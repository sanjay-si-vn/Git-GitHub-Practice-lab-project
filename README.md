# Git & GitHub Practice Lab

A hands-on repository created to practice Git, GitHub, and collaboration workflows used by DevOps and Cloud Engineers.

## Objectives

Practice:

* Git fundamentals
* Branching strategies
* Pull Requests
* Merge conflicts
* GitHub Actions
* Releases and Tags
* Troubleshooting scenarios
